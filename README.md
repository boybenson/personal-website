# Benson Yeboah — Portfolio

A responsive React + Tailwind portfolio for Benson Yeboah, focused on software engineering, payments, distributed systems, mathematics, and technical writing.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The app includes a responsive overview, a dedicated career history, dark-first theming, Medium articles, a searchable reading list, and an areas-of-focus page.
